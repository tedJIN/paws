orphan-check collects nothing

The orphan-check plugin runs one local shell script that reads your process list with ps and prints a table.

  • It makes no network calls.
  • It writes no files and stores nothing.
  • It never stops, signals, or changes any process.

What Claude does with the output follows your normal Claude Code settings; the plugin itself sends nothing anywhere.

Source: github.com/tedJIN/paws-orphan-check (MIT). Questions: pawsapp.help@gmail.com or GitHub issues.
