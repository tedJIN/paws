Privacy policy

Paws works only on this Mac

This is a draft and has not been reviewed by a lawyer.

Paws reads this Mac's memory and process list, shows them on screen, and ends the processes you pick.

What leaves the machine

  • License check. When a license key is registered, validated, or released, the key, this Mac's name, and an instance ID are sent to api.lemonsqueezy.com. Once at registration, then once every 7 days.
  • Update check. Once a day it reads a small file containing the latest version number. Nothing is sent.
  • Name list. Once a day it reads a small file that gives processes human-readable names. Nothing is sent. The list only changes names on screen — it never decides what gets ended.

Nothing else is sent anywhere. No usage statistics and no crash reports are collected.

What stays on the machine

~/Library/Application Support/Paws/ holds your settings, the record of actions taken (journal.jsonl), memory history, and the license file. The action record keeps the path and command line of every process that was ended. To erase it, delete that folder.

Problem reports

Pressing Report a problem in settings writes a diagnostic bundle to your desktop. It goes nowhere until you send it yourself. The bundle contains your settings, recent action records, the process list, and the macOS version. Command-line arguments are excluded — arguments often contain API keys. Only the file name in a path remains.

Instagram (@paws.appp)

Our Instagram account uses the Instagram API only for its own posts. When you comment on one of our posts, we read the comment (your username and text) to reply to it. If your comment is just the keyword PAWS, we send you one direct message with the download link. We keep the comment ID, username, text and our reply in a file on the maker's own computer, so the same comment is not answered twice. We do not sell or share it, and we never message anyone who did not comment.

Deleting your data: email pawsapp.help@gmail.com with your Instagram username and we will delete every record of your comments within 30 days. Deleting your comment on Instagram also stops any further reply.
