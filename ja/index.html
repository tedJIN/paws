なぜ遅くなるのか

ファンは回るのに、犯人が見えない

Macが遅くなると、私たちは一番重いアプリを探します。けれどAIツールを何個も動かすMacでは、犯人はリストの一番上ではなく、リストの外にいます。

重い作業が終わってずいぶん経つのに、ファンが回り続けます。

ウインドウをいくつも開いていないのに、スクロールが粘り、アプリの切り替えがもたつきます。

「アプリケーションメモリが不足しています」と出ます。名指しされたアプリを終了しても、しばらくするとまた出ます。

アクティビティモニタを開いても数百行あって、どこから見ればいいのか分かりません。

この四つが揃うときは、たいてい大きなアプリ一つではなく、小さなプロセスが数百個積み上がっています。 一つひとつには何の落ち度もないので、警告もアクティビティモニタもそれを名指しできません。

「自分のMacでも数えてみればいいのでは」

一行では無理です。この文章を書いているMacで親のないプロセスを数えると、こうなります。

$ ps -eo ppid= | awk '$1==1' | wc -l 798

約800個すべてが「親なし」ですが、そのうち片づける対象は0個です。 SpotifyもNotionもSafariのタブも、Appleのオーディオヘルパー数十個も、親はlaunchdです。 親がいないことは孤児である証拠ではなく、ただ情報がないという意味です。 本物の孤児と、きちんと働いているプロセスを見分けること — それがPawsのする仕事です。

見つけるもの

なぜ遅いのかを名指しで伝えます

メモリをどれだけ使っているかを見せるツールはたくさんあります。Paws はその先で、どれが持ち主を失ったのかを判定します。

01

孤児プロセス

親が終了して残されたプロセス。同じコマンドが3つ以上溜まったときだけ候補になります。1つだけなら放っておきます。

02

セッションのない大きなプロセス

どのターミナルも保持していないのに、メモリを大量に使っているもの。Paws が自分で終了することはなく、一覧に出すだけです。

03

メモリプレッシャー

メニューバーのリングが状態を色で伝えます。平常時はグレー、警告でオレンジ、危険で赤。グラフでそこに至る経緯がわかります。

どう働くのか

推測しません。
カーネルに尋ねます

何を消すかより、何を残すかのほうが難しい問題です。Pawsは四つの段階でその判断を絞り、確信がない段階では止まります。

01

見張る

5秒ごとにメモリ圧力とスワップを、15秒ごとにプロセス一覧を読みます。画面にあるのはメニューバーのリング一つだけです。

作業に影響なしPawsが使うメモリは100 MB以内。直近15分だけ覚えて、あとは捨てます。

02

判定する

「忙しいか」ではなく「セッションが握っているか」を尋ねます。カーネルがターミナルの前に置いたグループ（e_tpgid）を見て、保護は親のほうへ上に広がります。

作業に影響なしターミナルが握っているものと、その下にぶら下がるものはすべて保護します。入力を待ってCPUが0のAIセッションも同じです。

03

絞る

同じコマンドが三つ以上積み上がったものだけを候補にします。AppleのXPCサービスとApp Extensionは最初から候補になりません。

作業に影響なし一つしかないプロセスは、ただ働いている最中かもしれません。確信がなければ一覧に載せません。

04

人が選ぶ

片づけの一覧は、チェックが全部外れた状態で開きます。選んだものだけを終了し、何をいつなぜ終了したかを1年分残します。

作業に影響なし自動の片づけは初期状態でオフです。オンにしても、03を通った孤児だけが対象です。

この判断を一度間違えました

最初の版は、launchctlの一覧にないものを孤児と見なしました。その基準でAppleのXPCサービス108個を、正常なのに終了させました — その中にはSafariのWebコンテンツプロセスもありました。 100個の合成テストが全部通った状態で出た版です。一覧にないことは孤児の証拠ではなく情報の不在でしたが、偽のプロセスだけで試していては分かりませんでした。

今は実機で「健全なMacなら自動の片づけ対象は0個か」を確かめるテストがビルドごとに走ります。判定の規則はあの日から六つに増え、どれも「分からなければ何もしない」を既定値にしています。

しないこと

作業を失わせるツールは
使う価値がありません

整理アプリで一番大事なのは、何を消すかではなく何を残すかです。

  • 保護

    ターミナルが保持しているものには触れません

    その配下にぶら下がるものもすべて保護されます。入力待ちの AI セッションも含みます。

  • 保護

    何も事前にチェックしません

    整理リストは空の状態で開きます。終了するプロセスはすべて人が選んだものです。

  • 保護

    データはこの Mac から出ません

    利用統計もクラッシュレポートもありません。唯一の例外はライセンス確認です。

  • 保護

    記録のない終了はしません

    終了する前にもう一度確認し、何を・いつ・なぜ終了したかを書き残します。判断が不確かなときは何もしません。

CPU ゼロはアイドルではありません。 入力待ちの Claude Code の CPU 使用は 0 です。CPU で判断する整理ツールはそれを殺してしまいます。 Paws はカーネルがターミナルの前面に置いたグループ e_tpgid を読みます。忙しいかどうかではなく、セッションが保持しているかを問います。
