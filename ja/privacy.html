プライバシーポリシー

Paws はこの Mac の中だけで動きます

これは草案で、弁護士の確認を受けていません。

Paws はこの Mac のメモリとプロセス一覧を読み取って画面に表示し、あなたが選んだプロセスを終了します。

マシンの外に出るもの

  • ライセンス確認。ライセンスキーを登録・検証・解除するとき、キー、この Mac の名前、インスタンス ID が api.lemonsqueezy.com に送られます。登録時に1回、その後は7日ごとに1回です。
  • アップデート確認。1日1回、最新バージョン番号が書かれた小さなファイルを読みます。何も送信しません。

ほかには何もどこにも送信しません。利用統計もクラッシュレポートも収集しません。

マシンに残るもの

~/Library/Application Support/Paws/ には設定、処理の記録(journal.jsonl)、メモリの履歴、ライセンスファイルが保存されます。処理の記録には終了したすべてのプロセスのパスとコマンドラインが残ります。消すにはそのフォルダを削除してください。

問題の報告

設定で問題を報告を押すと、デスクトップに診断パックが作られます。あなたが自分で送るまでどこにも行きません。パックには設定、最近の処理記録、プロセス一覧、macOS のバージョンが含まれます。コマンドライン引数は含まれません — 引数には API キーが入っていることが多いからです。パスはファイル名だけが残ります。
