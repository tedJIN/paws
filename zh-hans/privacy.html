隐私政策

Paws 只在这台 Mac 上工作

本文为草案，尚未经过律师审阅。

Paws 读取这台 Mac 的内存和进程列表并显示在屏幕上，然后结束你选中的进程。

会离开电脑的内容

  • 许可证验证。注册、验证或释放许可证密钥时，密钥、这台 Mac 的名称和实例 ID 会发送到 api.lemonsqueezy.com。注册时一次，之后每 7 天一次。
  • 更新检查。每天读取一次包含最新版本号的小文件。不发送任何内容。

除此之外不向任何地方发送任何内容。不收集使用统计，也不收集崩溃报告。

留在电脑上的内容

~/Library/Application Support/Paws/ 中保存着你的设置、操作记录(journal.jsonl)、内存历史和许可证文件。操作记录会保留每个被结束进程的路径和命令行。要清除它，删除该文件夹即可。

问题报告

在设置中点按报告问题,会在桌面上生成诊断包。在你亲自发送之前，它不会去任何地方。诊断包包含你的设置、最近的操作记录、进程列表和 macOS 版本。不包含命令行参数 — 参数里常常带有 API 密钥。路径中只保留文件名。
