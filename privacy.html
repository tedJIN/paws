Paws 는 이 맥에서만 일합니다

이 문서는 초안이며 법률 검토를 거치지 않았습니다.

Paws 는 이 맥의 메모리와 프로세스 목록을 읽어 화면에 보여주고, 사용자가 고른 프로세스를 끝내는 도구입니다.

기계 밖으로 나가는 것

  • 라이선스 확인. 라이선스 키를 등록·검증·해제할 때 api.lemonsqueezy.com 에 키, 이 맥의 이름, 인스턴스 ID 를 보냅니다. 등록할 때 한 번, 그 뒤로는 7일마다 한 번입니다.
  • 업데이트 확인. 하루 한 번 새 버전 번호가 적힌 작은 파일을 읽습니다. 보내는 것은 없습니다.
  • 이름 목록. 하루 한 번 프로세스를 사람 말로 부르기 위한 목록 파일을 읽습니다. 보내는 것은 없습니다. 목록은 화면에 보이는 이름에만 쓰이고, 무엇을 끝낼지 정하는 데는 쓰이지 않습니다.

그 외에는 어떤 데이터도 보내지 않습니다. 사용 통계와 크래시 리포트를 수집하지 않습니다.

기계 안에 남는 것

~/Library/Application Support/Paws/ 에 설정, 조치 기록(journal.jsonl), 메모리 이력, 라이선스 파일이 있습니다. 조치 기록에는 끝낸 프로세스의 경로와 명령줄이 남습니다. 지우고 싶으면 그 폴더를 지우면 됩니다.

문제 신고

설정에서 문제 신고 를 누르면 바탕화면에 진단 묶음을 만듭니다. 사용자가 직접 보내기 전에는 아무 데도 가지 않습니다. 묶음에는 설정, 최근 조치 기록, 프로세스 목록, macOS 버전이 들어 있습니다. 명령줄 인자는 제외합니다 — 인자에 API 키가 들어 있는 경우가 흔하기 때문입니다. 경로의 파일 이름만 남습니다.

인스타그램 (@paws.appp)

Paws 인스타그램 계정은 우리 게시물에 한해 인스타그램 API 를 씁니다. 우리 게시물에 댓글을 달면 답글을 달기 위해 그 댓글(사용자 이름과 내용)을 읽습니다. 댓글이 키워드 PAWS 하나뿐이면 다운로드 링크를 담은 메시지를 한 번 보냅니다. 같은 댓글에 두 번 답하지 않도록 댓글 ID, 사용자 이름, 내용, 우리 답글을 만든 사람의 컴퓨터에 파일로 남깁니다. 팔거나 넘기지 않으며, 댓글을 달지 않은 사람에게는 메시지를 보내지 않습니다.

데이터 삭제: 인스타그램 사용자 이름을 적어 pawsapp.help@gmail.com 으로 보내 주시면 30일 안에 그 댓글 기록을 모두 지웁니다. 인스타그램에서 댓글을 지워도 이후 답글은 달리지 않습니다.
